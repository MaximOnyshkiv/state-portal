# Державний портал

Єдина система для державних фракцій RP-сервера: розділи фракцій, склад, ранги, документи, канцелярія; міжвідомчі запити й обмін документами; публічна сторінка для громадян (новини, накази, розшук, скарги, запис на прийом); нагляд Уряду і СБУ; адмінпанель. Список фракцій — змінна `FACTIONS` (`код:Назва:Опис,…`, код `gov` = наглядовий орган) або адмінпанель.

## Локальний запуск
```
npm install
npm start            # http://localhost:3100  (PORT=… щоб змінити)
```
Без `DATABASE_URL` використовується SQLite у `data/`. З `DATABASE_URL` — Postgres (схема створюється автоматично).

Демо-акаунти (пароль `demo1234`, усі позначені «[Приклад]»): demo_admin, demo_gov (мер, Уряд), demo_sbu (голова СБУ), demo_npu_lead (лідер НПУ), demo_npu (співробітник, ранг 4), demo_npu2, demo_moz, demo_dsns
Вимкнути демо: `SEED_DEMO=0`. Перший справжній адмін: `ADMIN_LOGIN` + `ADMIN_PASSWORD`.

## Деплой на Render
1. Створити репозиторій на GitHub і запушити: `git remote add origin … && git push -u origin master`.
2. Render → New → Blueprint → обрати репозиторій (`render.yaml` вже є).
3. Задати `DATABASE_URL` (окрема Postgres БД!), `ADMIN_LOGIN`, `ADMIN_PASSWORD`.

## Ролі
- Гість: публічна сторінка, скарги, запис на прийом.
- Співробітник: своя фракція (склад, документи; таємні — з рангу 8), міжвідомча взаємодія своєї фракції. Накази/директиви — з рангу 9.
- Лідер (роль leader або ранг 11+): прийом, ранги, звільнення у своїй фракції.
- Уряд і СБУ (наглядові органи): бачать усі фракції, всі запити й обмін; лідери/ранг 9+ можуть приймати, змінювати ранги та звільняти в будь-якій іншій фракції (включно один в одному); кожне кадрове рішення — у журналі «Нагляд».
- Адмін порталу: усе + користувачі, фракції, ранги, повний журнал.
